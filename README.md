# 아이돌 생일카페 정보 플랫폼 (최애생카)

이 프로젝트는 K-pop 팬덤을 위해 흩어져 있는 아이돌 생일카페 이벤트 정보를 **통합**하고, 팬/주최자가 누구나 손쉽게 **등록·검색**할 수 있는 웹 서비스를 구축하기 위해 진행되었습니다.  
사용자는 메인 화면에서 오늘/다가오는 생일카페를 카드 형태로 확인할 수 있으며, 주최자는 로그인 후 행사 정보를 등록해 다른 팬들과 공유할 수 있습니다. 또한 웹 크롤러로 SNS에 산재한 정보를 자동 수집하고, **RAG AI 기반 검색/추천**을 시험적으로 적용하는 것을 목표로 했습니다.

---

## 주요 기능

- **생일카페 통합 플랫폼**: 날짜·그룹·지역별로 분산된 정보를 한 곳에서 제공
- **반응형 UI/UX**: 메인 카드형 UI, 상세 페이지, 로그인/회원가입, 등록/관리(관리자) 페이지 제공
- **이벤트 검색**: 기간(오늘/이번 주 등) + 그룹/날짜/지역 필터, 키워드 검색, 상세 정보(장소·기간·특전 등) 표시
- **이벤트 등록/관리**: 주최자 등록/수정/삭제, 관리자 페이지에서 목록/키워드 검색 및 삭제
- **자동 크롤링 & RAG AI(실험)**: SNS 자동 수집·검증 크롤러 + RAG 기반 검색/컨셉 추천 기능을 시험 적용

---

## 역할

팀 단위로 진행되었으며, 본인은 **크롤링·백엔드**를 담당했습니다.

- **프론트엔드/디자인**: 메인·상세·등록·관리 화면 UI 구현, 반응형 레이아웃 설계
- **AI·백엔드**: RAG AI 및 추천 기능 구현, 서버·API 개발
- **크롤링·백엔드(본인)**:
  - Python 크롤러로 SNS 생일카페 공지글을 수집 → JSON 정제 → DB 자동 입력
  - PHP 기반 REST/백엔드 로직 및 관리자 페이지 구현
  - MySQL 데이터 모델 설계 및 백엔드 연동

---

## 기술 스택

- **언어**: PHP 8.1, Python, JavaScript(ES6)
- **프레임워크/라이브러리**: Bootstrap 5, Flask, SentenceTransformers, FAISS, LangChain(RAG), BeautifulSoup, Selenium
- **데이터베이스**: MySQL 8.0
- **서버**: Apache 2.4
- **도구**: VS Code, Git
